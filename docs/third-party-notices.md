# Third-party software and asset inventory

This inventory was checked against the production dependency closure in the lockfile for EverDash 0.1.0. The repository and image should be re-audited whenever dependencies or shipped assets change. Package names and versions are listed in `package-lock.json`; license texts are provided by the corresponding npm packages in the container build.

| Use | Packages | License inventory |
| --- | --- | --- |
| Browser runtime | `preact` | MIT |
| Server runtime | `fastify` and its production dependency tree | 49 packages total: 42 MIT, 4 BSD-3-Clause, 3 ISC |

The BSD-3-Clause packages in the current runtime closure are `fast-uri` (3.1.8 and 4.2.2), `light-my-request` (6.8.0), and `secure-json-parse` (4.1.1). The ISC packages are `fastq` (1.20.3), `semver` (7.8.5), and `split2` (4.2.0). The remaining production packages report MIT in their package metadata. Development-only packages are not copied into the runtime image; their current lockfile metadata must still be included in a source distribution review.

The Home Screen and manifest icons are generated by `scripts/generate-icons.mjs` from project-authored vector geometry. `public/icons/home.svg` is project artwork. No external font, stock image, or third-party raster artwork is shipped. The Pstryk and Home Assistant integration links in the README document upstream data formats and APIs; they are not bundled code or artwork.

EverDash itself is licensed under the MIT License in the root `LICENSE` file. This notice is an attribution inventory; it does not replace third-party license terms. Before public release, review whether any upstream license requires additional full-text notices or source-distribution terms.

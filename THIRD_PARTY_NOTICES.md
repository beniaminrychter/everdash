# Third-party software and asset inventory

This inventory covers the server runtime and browser bundles for EverDash 0.2.0. The repository and image should be re-audited whenever dependencies or shipped assets change. Package names, versions, and license metadata are listed in `package-lock.json`; license texts are provided by the corresponding npm packages.

| Use | Packages | License inventory |
| --- | --- | --- |
| Tablet browser runtime | `preact` and its production dependency tree | MIT and transitive package terms listed in the lockfile |
| Home Assistant admin browser bundle | `react`, `react-dom`, `@base-ui/react`, `lucide-react`, `qrcode.react`, and shadcn-derived components | Package license metadata is listed in the lockfile; generated shadcn component patterns are MIT |
| Server runtime | `fastify` and its production dependency tree | Package license metadata is listed in the lockfile |

The application build dependencies include React, Base UI, Tailwind, Vite, and shadcn CLI. They are not copied as Node modules into the runtime image. React, Base UI, and icon/QR code implementations are included in the admin browser bundle, so their package license terms remain relevant to the distributed image.

The Home Screen and manifest icons are generated by `scripts/generate-icons.mjs` from project-authored vector geometry. `public/icons/home.svg` is project artwork. No external font, stock image, or third-party raster artwork is shipped. The Pstryk and Home Assistant integration links in the README document upstream data formats and APIs; they are not bundled code or artwork.

EverDash itself is licensed under the MIT License in the root `LICENSE` file. This notice is an attribution inventory; it does not replace third-party license terms. Before public release, review whether any upstream license requires additional full-text notices or source-distribution terms.
